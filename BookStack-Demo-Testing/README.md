# QA Assignment – BookStack Demo

## Application Details
- Application: BookStack Demo
- Test account: `admin@example.com`
- Testing: Functional testing, bug hunting, automation planning

## Scope
1. Functional testing: positive, negative, boundary-value, and edge-case scenarios.
2. Bug hunting: document reproducible defects with evidence.
3. Test automation: select three suitable scenarios and justify automation.

## Files
- `Test-Cases.xlsx` — functional test cases and execution result fields
- `Bug-Report.md` — bug report template
- `Automation.md` — three automation candidates and justifications
- `Evidence/` — screenshots or proof
